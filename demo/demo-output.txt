$ cat tests/samples/win-smartscreen.txt | explainthis
What it says: Windows SmartScreen blocked an unrecognised app
Meaning: Windows cannot check this program's reputation. That is not proof of a virus: new or small programs often show this. It also means Windows has no evidence the program is safe.
What you can do:
  1. Check where you got it. Prefer the official site of the program.
  2. Look at the file's digital signature: right-click the file, Properties, Digital Signatures. An unsigned file is not proof of danger, but ask whether you trust the source.
  3. Compare the file's SHA-256 (`Get-FileHash FILE` in PowerShell) with the one on the official page, if they publish it.
  4. Scan it with Microsoft Defender, or upload it to virustotal.com.
If you take the tempting shortcut: 'More info' then 'Run anyway' lets the program start with your user's permissions. If it is malware it can read your files and saved passwords. ExplainThis never clicks it for you.
Risk: High
