What it does

Run your command through explainthis run and it explains the error only if the command fails: what it means, where it happened, what you can do, and what is dangerous about the tempting shortcut. It can also follow a log file, read the clipboard or OCR a screenshot of a warning. It never runs a fix or clicks Allow for you, and no AI service is involved.

Examples

Real output (python run, Windows warning text, Arabic)

$ explainthis run -- python3 /tmp/t1.py
Traceback (most recent call last):
  File "/tmp/t1.py", line 1, in <module>
    import cv2
ModuleNotFoundError: No module named 'cv2'

--- ExplainThis: the command exited with code 1 ---
What it says: Python cannot find the module 'cv2'
Where: /tmp/t1.py:1 (<module>)
Code: import cv2
Meaning: The module is not installed in the Python that ran your script, or its name is spelled differently.
What you can do:
  1. Install it with the same Python that failed: `python3 -m pip install opencv-python`.
  2. The pip name can differ from the import name (here: `cv2` is installed as `opencv-python`). Check the spelling on pypi.org before installing: a one-letter typo can be a different package.
  3. If you use a virtual environment, activate it first.
(ExplainThis never runs a fix or clicks anything for you.)

$ cat tests/samples/win-smartscreen.txt | explainthis
What it says: Windows SmartScreen blocked an unrecognised app
Meaning: Windows cannot check this program's reputation. That is not proof of a virus: new or small programs often show this. It also means Windows has no evidence the program is safe.
What you can do:
  1. Check where you got it. Prefer the official site of the program.
  2. Look at the file's digital signature: right-click the file, Properties, Digital Signatures. An unsigned file is not proof of danger, but ask whether you trust the source.
  3. Compare the file's SHA-256 (`Get-FileHash FILE` in PowerShell) with the one on the official page, if they publish it.
  4. Scan it with Microsoft Defender, or upload it to virustotal.com.
If you take the tempting shortcut: 'More info' then 'Run anyway' lets the program start with your user's permissions. If it is malware it can read your files and saved passwords. ExplainThis never clicks it for you.
Risk: High
(ExplainThis never runs a fix or clicks anything for you.)

Install

Windows

Install Python 3.9+ from python.org (tick "Add python.exe to PATH"), then in PowerShell:
py -m pip install git+https://github.com/mohamed-elshamy-ai/explainthis
py -m pip install .
explainthis run -- python app.py
Untested. Should work. Only tested on Linux.

macOS

Python 3.9+ (brew install python or python.org), then in Terminal:
python3 -m pip install git+https://github.com/mohamed-elshamy-ai/explainthis
pip install .
explainthis run -- python app.py
Untested. Should work. Only tested on Linux.

Linux

Python 3.9+ is usually installed. In a terminal:
python3 -m pip install --user git+https://github.com/mohamed-elshamy-ai/explainthis
pip install .
explainthis run -- python app.py
Tested. Tested on Linux (Python 3.10). Screenshots need tesseract.

How it worksإزاي بيشتغل

  1. The text comes from the command, a pipe, a log, the clipboard or OCR of a screenshot.
  2. It finds where it happened (file, line, code).
  3. It matches the message against 28 hand-written entries, filling in details like the module name.
  4. It prints meaning, steps, the consequence of the risky shortcut and a risk level, in English or Arabic.
  5. If the message is unknown it says so and shows the key line instead of guessing.

Honest limits

  • Only 28 kinds of message are known. Anything else gets an honest 'no built-in explanation'. No AI model.
  • Screenshots are read with OCR text only. It does not understand pictures or icons.
  • No global shortcut, region picker or tray app yet. Clipboard and screen capture are untested.
  • Windows entries were not run on a Windows machine.
  • It gives general advice. It cannot see your machine.
